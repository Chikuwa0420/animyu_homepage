# ANIMUSEUM! Homepage

![web.image](./images/explain/web.explain1.png)
## 概要 (Overview)
新潟大学サークル「あにみゅ！」主催の、サブカルチャー楽曲DJイベントのホームページ。
イベントキャラの3Dモデルを投影するAR機能を搭載した。(自分で製作した別リポジトリのサイトへ移動する)

## 機能 (Features)

- ANIMUSEUM!イベント関連情報

- Tools ボタンより-
- VIEW
  イベント公式キャラクターである「あにみゅ子ちゃん」の3DモデリングをARで見ることができる。
  
- AR
あにみゅ子ちゃんの3Dモデリングを画面タップによってアニメーションさせることが出来る。専用のマーカーをスキャンした時のみ、モデルが投影される。

-LIVE
イベント中に使用できる二つのモードが搭載される。
1.うちわモード:点滅する文字の書き込み。色の変更が可能。
2.ペンライトモード:画面全体に単色が表示。色の変更可能。
